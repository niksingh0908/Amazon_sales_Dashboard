# Amazon Sales Analysis Dashboard 📊

An interactive **Tableau dashboard project** built to analyze Amazon
sales performance across revenue, cost, profit, orders, sales channels,
product categories, and shipping performance.

## 📌 Project Overview

This project transforms Amazon sales data into an interactive Tableau
dashboard with three analytical pages:

1.  **Executive Page** -- high-level sales and operational performance
2.  **Item Analysis** -- category-level revenue, cost, orders, and
    profit
3.  **Revenue Analysis** -- yearly revenue trends and average shipping
    days

The dashboard is designed to help identify major sales trends,
high-performing product categories, operational patterns, and areas that
may require further business attention.

## 🎯 Objectives

-   Analyze year-wise order and revenue trends
-   Compare **Online vs. Offline** sales channels
-   Understand order distribution by priority
-   Identify the strongest product categories
-   Compare category-level revenue, cost, and profit

## 🗂️ Dataset

The project uses an Amazon sales dataset containing **1,717 records and
11 columns**.

### Dataset Columns

### Dataset Columns

| Column | Description |
|---|---|
| `Country` | Country associated with the order |
| `Item Type` | Product category/type |
| `Order Date` | Date the order was placed |
| `Order ID` | Unique order identifier |
| `Order Priority` | Priority of the order |
| `Region` | Sales region |
| `Sales Channel` | Online or Offline |
| `Ship Date` | Date the order was shipped |
| `Total Cost` | Total cost of the order |
| `Total Revenue` | Revenue generated by the order |
| `Units Sold` | Number of units sold |

# 🔍 Key Business Insights

### 1. Offline is the larger sales channel

The dashboard's sales-channel analysis shows **59.15% Offline** compared
with **40.85% Online**, indicating a larger contribution from the
offline channel.

### 2. 2012 was the strongest year in the analysis

2012 recorded both the **highest order volume (405)** and the **highest
revenue (\$555.39M)** among the years shown.

### 3. Revenue declined after the 2012 peak

Revenue fell from **\$555.39M in 2012 to \$152.41M in 2017**,
representing a substantial decline over the period.

### 4. Cosmetics is the strongest product category

Cosmetics generated approximately **\$724.38M in revenue**, **\$288.08M
in profit**, and **261 orders**, making it the strongest category across
the main performance measures shown.

### 5. Shipping performance improved by 2017

Average shipping days decreased from **25.3 days in 2010 to 18.9 days in
2017**.

### 6. Faster shipping did not consistently correspond to higher revenue

2017 had the **lowest average shipping time (18.9 days)** but also the
**lowest revenue (\$152.41M)** in the displayed period. This suggests
that shipping speed alone does not explain revenue performance.
